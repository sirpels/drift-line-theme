# Drift Line Theme

A custom Shopify Online Store 2.0 theme built from scratch for Go Crazy, a premium Nigerian streetwear brand.

## Project Goal

To design and develop a modern Shopify storefront that feels premium, performs fast, and showcases advanced Shopify theme development skills.

## Features

- Custom Shopify theme
- Dark / Light mode
- Smooth animations
- Mobile-first design
- Responsive layouts
- Collection filtering
- Product recommendations
- Performance optimized
- AI-assisted development workflow

## Tech Stack

- Shopify Liquid
- HTML5
- CSS3
- JavaScript (ES6)
- Shopify CLI
- Git
- VS Code
